### Quavely

**Quavely** is a web application built with **React** that helps users explore earthquake activity in a more interactive and informative way.

🔗 **Live Website:** [quavely.netlify.app](https://quavely.netlify.app)

#### What Quavely Does
- Lets users explore earthquake activity based on a selected **region**
- Filters earthquake data by **radius**
- Allows users to choose a **time range**
- Presents earthquake history and more detailed analysis in an accessible format

#### My Contribution
- Co-engineered the application using **React**
- Helped build the structure and user-facing experience
- Contributed to making earthquake data easier to explore and understand
